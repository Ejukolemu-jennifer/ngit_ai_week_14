 # Prompt Engineering Evaluation

This document contains the actual outputs generated by the Llama-3.1-8b-instant model and evaluates the differences between Zero-shot and Few-shot prompting techniques.

## 1. Generated Outputs

### Task 1: Summarization
* **[Zero-shot Summary Output]:**
  The company's Data Retention Policy requires customer financial transaction records to be retained for at least 7 years, stored in fully encrypted form, and audited monthly.
  * **[Few-shot Summary Output]:**
    The Data Retention Policy requires customer financial transaction records to be retained for at least 7 years, stored securely, and audited monthly.

    ### Task 2: Information Extraction
    * **[Zero-shot Extraction Output]:**
      - Data Retention Period: 7 years
        - Encryption Standard: AES-256
        * **[Few-shot Extraction Output]:**
          - Retention Period: 7 years
            - Encryption Standard: AES-256
              - Audit Frequency: Monthly
                - Consequence of Unauthorized Data Sharing: Immediate suspension

                ### Task 3: Q&A
                * **[Zero-shot Q&A Output]:**
                  According to the Data Retention Policy (v4.2), if someone shares data without authorization, they will be subject to immediate suspension.
                  * **[Few-shot Q&A Output]:**
                    Immediate suspension.

                    ---

                    ## 2. Technique Analysis & Observations

                    ### Summarization Task
                    * **Zero-shot Observation:** The model provided a clean, accurate one-sentence summary but included minor conversational text elements.
                    * **Few-shot Observation:** By giving the model an explicit example sentence structure, the summary became more structured and straight to the point.

                    ### Information Extraction Task
                    * **Zero-shot Observation:** The model successfully extracted the correct key-value pairs but added bullet points automatically based on its own internal formatting defaults.
                    * **Few-shot Observation:** The model closely followed the custom example format provided, matching the exact spacing and labeling constraints seamlessly.

                    ### Q&A Task
                    * **Zero-shot Observation:** The model answered completely, but wrote a long sentence starting with conversational filler ("According to the Data Retention Policy...").
                    * **Few-shot Observation:** Because the example provided a direct, single-phrase answer style ("12 characters."), the model adapted perfectly and answered the question using just two clear words ("Immediate suspension.").config/
