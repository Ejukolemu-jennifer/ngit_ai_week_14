  # Corporate Policy Prompt Engineering
This project applies Zero-Shot and Few-Shot prompt engineering techniques to analyze and extract information from a corporate Data Retention Policy using the Groq API and a Llama 3.1 model.

## Submission Files
* **Prompt.py** - The Python script containing the policy text data, custom prompt templates, and API call functions.
* **evaluation.md** - A documentation file holding the model's generated text outputs and an analysis comparing the prompting methods.
* **ReadMe.md** - This file, providing a brief overview of the project and submission contents.

## Project Tasks Covered
1. **Summarization:** Condensing the policy text into a single, concise sentence.
2. **Information Extraction:** Pulling out key-value pairs (retention periods and encryption standards).
3. **Question Answering (Q&A):** Answering direct policy questions using both zero-shot and few-shot styles.
